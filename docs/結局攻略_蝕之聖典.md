## 建議順序

**一、先把選項類的掃掉**（進去點兩下就有，最快）

1. **CROWN** → 01、02（兩次，各選一邊）
2. **CHALICE** → 04（沒有動）、03（擋 → 提醒 → 輸）、19（擋 → 提醒 → 贏）
3. **SPIRAL** → 07；再一次選另一邊拿 08（黃符文要 ≥3）
4. **TRUCE** → 12

**二、要打輸的**（戰鬥沒有「投降」，得真的輸）

5. **SEANCE** → 16（第一場贏、第二場輸）、14（兩場都輸）
6. **PARTING** → 17（ch4bt3 輸）
7. **COMMUNION** → 15（克蘿伊戰輸）
8. **VIGIL** → 10（米夏戰贏）、11（米夏戰輸 → 被震開）

**三、要養西碧兒的**（WHISPER，最花時間，放最後）

9. **WHISPER**（分歧選「告訴薇狄亞」）→ 三個夜都點薇狄亞做儀式 → 儀式當天選「和薇狄亞聯手」→ 05
10. **WHISPER**（選「先不說出去」）→ 三個夜都點西碧兒 → 擁抱那晚沒人看見 → 20
11. 同上，但事先讓薇狄亞好感也到 45（白天多陪她）→ 擁抱那晚被撞見 → 13
12. **WHISPER** → 三個夜隨便點 → 儀式當天選「按住梅爾」→ 06

**四、18 終焉**

PARTING 的三個選項各自看自己顏色的符文（藍／紅／黃 ≥3）。挑一個**你符文不足**的顏色去追，就會撲空 → 落單 → 夢境 → 選「要結束了，對嗎？」→ 18。

⚠️ 如果四色符文都滿了，這個結局就拿不到了——聖典會把你歷來的符文全借給你，三條路都會成功。詳見下面。

**五、09 小精靈，飛走了**

聖典拿不到。它的分歧點在 `chapter5yellow` 第 152 行（`IsSecondPlaythrough() && RunesYellow()>=5`），而 SPIRAL 進去的位置是 173 行，已經過了那個判斷。只能正規跑二週目，而且要真的把涅莉五場儀式都打贏。

## 幾個會卡住的點

**08 會變成 07**：`#realworld` 開頭有 `@if RunesYellow()<3 → @goto .eclipse`。黃符文不足時，選了「和我走吧」還是會掉進輪迴の鑰匙。先去把涅莉的儀式打三場。

**07 不受 bossPower 影響**：`#eclipse` 有 `@if bossPower==2 → eclipse_lost`（賣掉蝕之聖典會封死輪迴の鑰匙），但從聖典進去時 bossPower 是未定義的，NCalc 求值失敗＝條件不成立，所以拿得到。

**13 和 20 的門檻**：「先不說出去」給 +5，三個地圖夜是 syb_day01（+10）、syb_day02（+15）、syb_day03（+20），三晚剛好 50。13 和 20 的差別不在西碧兒，在**薇狄亞**——她好感夠（Ved≥45）那晚就會來找你，於是站在門外看完了整段。

**14 和 16 的差別**在第一場戰鬥（ch4bt1）的勝敗：輸過就是壞滅，沒輸過就是魔蝕。兩個都要從 SEANCE 從頭跑。

## 一個設計上的死角

18 終焉需要「撲空」，但聖典進節點時會把你**歷來拿過的符文全部借給你**，所以四色都滿之後三條路都會成功，撲空再也發生不了。

可能的解法：讓選人面板的「都不選（好感全部從零開始）」順便**也不借符文**——玩家明確選擇「以什麼都沒有的狀態進去」，撲空類的結局就隨時拿得到，而且這個選擇是他自己按的，看得見。
