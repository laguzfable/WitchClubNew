# 綠線的結局邏輯，與西碧兒的三角關係

照 `chapter4green.nani`、`syb_day01~05`、`syb_end`、`badend13` 的實際內容整理。

## 一、綠線的骨架

**COMMUNION（`chapter4green` 從頭）**

1. 薇狄亞把大家帶去莉莉娜的場子，西碧兒請大家吃「蘇生」餅乾 → 魔力共鳴，所有人都嗨了
2. 克蘿伊來砸場 → **女巫獵人戰**
   - **輸 → 15 肅清**
   - 贏 → 西碧兒不殺她，反而對她下咒「賦予平等」（給獵人魔力），放她走
3. 薇狄亞：「這是最好的結局了，對吧？」→ 兩個選項**只影響台詞**，不影響分歧（兩邊都 +5 薇狄亞好感）
4. 三個地圖日

**WHISPER（`chapter4green#branch_green_tell`）**——梅爾告訴你儀式的真相之後，你要把這件事告訴誰：

| 選擇 | 走向 |
|---|---|
| 告訴薇狄亞（+5 Ved） | 薇狄亞去勸西碧兒 → 三個夜 → 西碧兒被說動、收手 → **05 深春** |
| 告訴西碧兒（+5 Syb） | 她要你替她除掉克蘿伊和梅爾 → 三個夜 → 暗殺當天的二選一 |

## 二、四個結局的歸屬

| 結局 | 是誰的 | 觸發 |
|---|---|---|
| 05 深春 | 薇狄亞 | 告訴薇狄亞 → 儀式當天，`affinity_Ved>=45`（三場儀式）→ 她說得動西碧兒 |
| 06 火中の幻影 | **薇狄亞** | 儀式完成。她要的從來只有「大家好好地在一起」，所以她不會攔也攔不住；火燒起來時她看見的還是那個畫面 |
| 13 唯一 | 薇狄亞 | 你替西碧兒動手，她全看見了 → 除掉你 |
| 20 私奔 | 西碧兒 | 三個夜都私底下去找她（`affinity_Syb>=50`） |

**06 跟西碧兒對你的態度無關。** 它的重量在那個幻覺，不在誰殺了誰。兩條路都會走到它：薇狄亞線好感不足（她說了但沒人聽），或西碧兒線沒被打動又收了手（儀式本來就不是靠你在推的）。

## 三、西碧兒線怎麼進去

她是隱藏角色，**選項裡不會出現她的名字，聖典的選人面板上也沒有她**。

1. WHISPER 的分歧選「**先不說出去**」（+5）——把梅爾告訴你的事壓下來，本身就是選邊。當晚她會來敲門。
2. 之後三個夜，地圖上有她，但**沒有人會提醒你**。三個夜都去找她：+10 / +15 / +20，加上前面的 +5 剛好 **50**。
3. 暗殺當天，好感夠的話**那一天根本不會發生**——沒有暗殺，也沒有二選一，她只是問你為什麼每天都來。→ **20 私奔**

沒被打動的話才會走到現場的二選一：

- **動手** → 13 唯一（薇狄亞看見了）
- **收手** → 06 火中の幻影（儀式照常完成）

分一個夜給薇狄亞就湊不到 50。這是刻意的：那三個夜就是「你把時間給了誰」。
